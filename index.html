Grammar Focus

Plural endings

7

Some nouns need -es. Focus on recognizing the pattern.

Add -s

key → keys
phone → phones
helmet → helmets

Add -es

watch → watches
box → boxes

Say it aloud: one watch → two watches · one box → two boxes.

Demonstratives

This or that?

11

Use this for one object near you and that for one object farther away.

THIS · near

This is my helmet.

The object is close to the speaker.

THAT · far

That is the radio.

The object is farther from the speaker.

Point to an object near you, then one farther away.
BOOKGrammar Bank 3B · p. 96
Demonstratives

These or those?

12

Use these and those for plural objects.

THESE · near

These are my gloves.

More than one object, close to you.

THOSE · far

Those are my boots.

More than one object, farther away.

Near + plural = these · Far + plural = those

Questions

Ask about objects

13

Use simple questions to identify an object or a group of objects.

QuestionAnswer
What is this?It’s a phone.
What is that?It’s a radio.
What are these?They’re keys.
What are those?They’re boots.
Notice: singular → is / it · plural → are / they.
